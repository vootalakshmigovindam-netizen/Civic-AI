You are an expert full-stack developer, AI engineer, UI/UX designer, database engineer, and beginner-friendly coding mentor.

I am a first-year B.Tech student with basic programming knowledge. Build a complete, functional, beginner-friendly web application for me in Replit.

PROJECT NAME:
CivicAI

PROJECT IDEA:
Create an AI-powered civic issue reporting platform where citizens can report real-world problems such as potholes, garbage dumps, broken streetlights, water leaks, damaged roads, and similar public infrastructure issues.

A citizen should be able to take/upload a photo of a problem. The application should use AI/computer vision to identify the type of problem, estimate its severity, extract or request the location, display the issue on a live map, and automatically create a structured complaint.

Citizens should be able to view their complaints and track their status.

Authorities should have a separate dashboard where they can view reported problems, filter them, update their status, and manage complaints.

IMPORTANT:
This is a student prototype. Prioritize a working, understandable application over unnecessarily complicated enterprise architecture.

==================================================

   ==================================================

Build a responsive web application with two main user types:

1. CITIZEN
2. AUTHORITY/ADMIN

The complete flow should be:

Citizen

===================
